# FOST London Deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the FOST London 2026 talk: five cut demo clips, the Slides artifact with the clips embedded, an offline PDF with the same clips embedded for Okular, and a run sheet.

**Architecture:** A small Python tool in `presentation/tools/` does everything repeatable: it cuts the clips from a JSON cut list with `ffmpeg`, makes QR codes, and injects MP4s into a PDF as Screen annotations with `pikepdf`. The deck itself is the Slides artifact `https://claude.ai/artifact/AUkTCc1xev8nuvEcBELiU2`: one `project/slides/<id>.html` per slide plus `project/deck.json`, written in the scratchpad and published in one call; clips and images are uploaded as the artifact's assets.

**Tech Stack:** ffmpeg (libx264), Python 3 + `pikepdf` + `qrcode[pil]` + `pytest` in a git-ignored venv, poppler (`pdfimages`, `pdftoppm`), the Slides artifact type (slide HTML subset, `data-video` on `<img>`), Okular.

**Spec:** [`presentation/deck-plan.md`](../../../presentation/deck-plan.md)

## Global Constraints

- Branch `docs/fost-deck-plan`; never commit to `main` directly (`CLAUDE.md`).
- Source clips `presentation/recordings/stage*-1080.mp4` stay untouched; outputs are `presentation/recordings/stage{1..5}-talk.mp4` (git-ignored).
- Clip format for the artifact: H.264 MP4, no audio, **≤ 20 MB each**, 1920×1080, 25 fps.
- Deck slide canvas 1920×1080, inline styles from the Slides subset only, text ≥ 24px, ≤ 200 elements per slide, speaker notes ≤ 4,000 characters in one trailing `<aside>`.
- Palette: navy `#323a4d`, beige `#ede3da`, content background `#fbfbf8`, text dark `#1f2533`, gate red `#c0392b` and green `#2e8b57` only for gate results, accent blue `#1d9bd1` (the old deck's icon blue).
- Type: Merriweather (headings), Roboto (body), JetBrains Mono (code), all Google Fonts.
- Repo QR target: `https://codeberg.org/pierogi/devops-api-governance`. FOST feedback QR: `https://portal.joinfost.io/feedback/d78fddb7-74c5-4a6c-851c-d0e0d4915e22/qrcode.png`.
- PZU is named on the agents slide. No `pzu:` rule IDs or PZU URLs from old screenshots.
- The artifact type forbids verification renders unless the user asks: no screenshots of the deck; Andrzej reviews it.

## Review Focus

- A clip over 20 MB is refused by the asset store → the cut tool fails the build if any output is over 19.5 MB.
- A cut that starts mid-typing or mid-page-load looks broken on a projector → every boundary is chosen from per-frame thumbnails, not the 4 s sheets.
- Okular shows only the poster for a Screen annotation with the wrong rendition structure → the two-slide Okular test gates the full PDF build; the injector test asserts the annotation structure.
- Clips loop in the artifact → each video slide's notes say "move on when the merge shows"; clip ends on a still merged state, never mid-action.
- Terminal text in clips is unreadable at the back of the room → every video slide is followed by a takeaway slide with the key line at ≥ 44px.

```python
# cut_clips.py
"""Cut the talk clips from the raw recordings, per cuts.json."""
import json, subprocess, sys
from pathlib import Path

MAX_BYTES = int(19.5 * 1024 * 1024)

def build_filter(parts):
    chains = [f"[{i}:v]trim=start={p['from']}:end={p['to']},"
              f"setpts=(PTS-STARTPTS)/{p['speed']}[v{i}]" for i, p in enumerate(parts)]
    joined = "".join(f"[v{i}]" for i in range(len(parts)))
    return ";".join(chains) + f";{joined}concat=n={len(parts)}:v=1:a=0,fps=25[out]"

def main(cuts_path, recordings_dir):
    cuts = json.loads(Path(cuts_path).read_text())
    outs = []
    for stage, parts in cuts.items():
        out = Path(recordings_dir) / f"{stage}-talk.mp4"
        cmd = ["ffmpeg", "-v", "error", "-y"]
        for p in parts:
            cmd += ["-i", str(Path(recordings_dir) / p["src"])]
        cmd += ["-filter_complex", build_filter(parts), "-map", "[out]", "-an",
                "-c:v", "libx264", "-preset", "slow", "-crf", "23",
                "-pix_fmt", "yuv420p", "-movflags", "+faststart", str(out)]
        subprocess.run(cmd, check=True)
        if out.stat().st_size > MAX_BYTES:
            sys.exit(f"{out} is over 19.5 MB; raise -crf")
        outs.append(out)
    return outs

if __name__ == "__main__":
    for o in main(sys.argv[1], sys.argv[2]):
        print(o)
```
